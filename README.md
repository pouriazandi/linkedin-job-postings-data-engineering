# LinkedIn Job Postings – Data Engineering & Analytics

## Overview

This university project focuses on the implementation of an ETL process
and a data warehouse for analyzing LinkedIn job postings from 2023–2024.

The dataset contains more than 124,000 job postings and includes information
about jobs, companies, skills, salaries, benefits, industries, and locations.

## Project Goals

- Analyze LinkedIn job postings
- Identify remote job opportunities
- Analyze salaries and payment structures
- Explore required skills
- Analyze companies, industries, and locations
- Explore job benefits and applicant activity

## Technologies

- Pentaho Data Integration
- SQL
- Data Warehouse
- Tableau
- ETL
- Data Visualization

## Project Structure

- `Pentaho files/` – ETL workflows and transformations
- `Tableau files/` – Tableau reports and data extracts
- `Data warehouse tables/` – Project datasets and warehouse tables
- `Documentation.pdf` – Project documentation

## Key Results

The project implements an ETL workflow, a data warehouse,
analytical queries, and reports for exploring LinkedIn job-posting data.
